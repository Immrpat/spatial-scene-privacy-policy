# Spatial Scene: Privacy Policy

Public privacy policy for **Spatial Scene**, an Android app published by **Namib** (`com.namib.spatialapp`).

**Website:** https://immrpat.github.io/spatial-scene-privacy-policy/

**Privacy contact:** pat@namibapp.com

This repository contains only the static privacy policy website.

## Preview locally

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8080/`.
